# firstspace

簡易的經費管理 CLI，方便輸入科目與額度，並在後續登記支出時即時計算各科目執行率與剩餘經費。

## 使用方式
1. 安裝需求：僅需 Python 3.10+（使用標準函式庫）。
2. 執行互動式工具：
   ```bash
   python budget_manager.py
   ```
3. 依提示輸入計畫名稱、開始與結束日期後，可選擇：
   - **新增科目**：逐筆輸入科目與經費額度。
   - **CSV 匯入科目**：CSV 需包含欄位 `科目`、`經費額度`（可含逗號千分位）。
   - **登記支出**：指定科目、支出金額，並可附註說明。
   - **查看報表**：列出各科目額度、累計支出、執行率與剩餘金額，以及總計摘要。

## 範例 CSV
```csv
科目,經費額度
人事費,1000000
設備費,500000
旅運費,150000
```

執行過程可多次查看報表，了解經費執行率及剩餘額度。
